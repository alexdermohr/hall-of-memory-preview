FAQ

Kurz gefragt.
Klar beantwortet.

Welche Event-Angebote gibt es aktuell?+

Zum Start stehen Fotobox, Fotospiegel und Magazinbox im Mittelpunkt. Die Website ist so aufgebaut, dass später weitere Event-Angebote ergänzt werden können.

Wie stelle ich eine Anfrage?+

Im Anfrageformular werden gewünschtes Produkt, Paket, Veranstaltungsdatum, Ort, Veranstaltungsart und Kontaktdaten zusammengeführt. Eine Anfrage ist noch keine verbindliche Buchung.

Wie erhalte ich nach dem Event meine Bilder?+

Vorgesehen ist ein geschützter persönlicher Link oder Code. Der Zugriff wird pro Veranstaltung getrennt, sodass ausschließlich die eigene Galerie erreichbar ist.

Kann ich direkt ein Paket auswählen?+

Ja. Sobald die finalen Paketnamen, Leistungen und Preise bestätigt sind, werden sie direkt bei den Angeboten und im Anfrageformular vergleichbar auswählbar.
